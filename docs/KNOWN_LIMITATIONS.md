# Known Limitations (v1)

**Date:** 2026-11-06  
**Document:** docs/KNOWN_LIMITATIONS.md

As documented in PRD Section 2.2 (Non-goals for v1):
1. **Medical Transfusion Approval:** The platform provides informational compatibility matching based on ABO/Rh antigens only. Clinical cross-matching must be performed by certified blood banks.
2. **Whole Blood Inventory Management:** The platform provides published availability statuses (AVAILABLE, LOW, UNAVAILABLE) and unit counts, but does not replace hospital laboratory information management systems (LIMS).
3. **Automated WhatsApp Messaging:** In compliance with WhatsApp policies and PRD Section 6.6, WhatsApp integration utilizes pre-filled click-to-chat links (`wa.me/?text=...`) rather than automated broadcast bots.
4. **Native Mobile Applications:** The v1 scope focuses on a responsive web application designed for mobile, tablet, and desktop viewports.
